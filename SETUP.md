# Install on your GitHub profile

1. Create (or open) the **public** GitHub repository named exactly `enio0` under the account `enio0`.
2. Upload `README.md` and the entire `assets/` folder from this package to the **root** of that repository.
3. Commit the changes. GitHub should then show the README on your profile.
4. Update the four project titles with exact repository links once verified.

The README uses only GitHub-compatible Markdown, HTML, and SVG/PNG files. It does not depend on external image services, badges, stats, or scripts.

Banner note: the image asset preserves the latest generated version with the binary date engraving.
